# @work4you/ui

Work4You shared React design system — components, hooks, utils, fonts, overlays.

## Install (monorepo)

This package lives in the Work4You monorepo as a workspace:

```bash
npm i @work4you/ui --workspace apps/desktop
```

## Styles

```css
@import '@work4you/ui/styles/fonts.css';
@import '@work4you/ui/styles/globals.css';
```

## Usage

```tsx
import { Button, Input } from '@work4you/ui'
```
