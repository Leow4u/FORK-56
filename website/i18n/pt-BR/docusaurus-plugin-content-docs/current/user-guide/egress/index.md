# Proxy de saída

Firewall opcional de injeção de credenciais de saída para sandboxes de terminal remoto. O sandbox mantém apenas tokens de proxy opacos; as chaves de API reais nunca saem do host.

- [iron-proxy](./iron-proxy) — proxy de interceptação TLS de binário único do [ironsh/iron-proxy](https://github.com/ironsh/iron-proxy), instalado sob demanda e gerenciado pelo `work4you egress`.
