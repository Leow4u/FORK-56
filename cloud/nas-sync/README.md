# NAS sync (Etapa 2)

Canonical copies of `work4you-account-service` provision files, pushed by
`.github/workflows/sync-nas-cloud-etapa2.yml`.

**One-time:** add GitHub secret `NAS_REPO_TOKEN` on FORK-56 (PAT with write access
to `Leow4u/work4you-account-service`).

**Run:** Actions → **Sync NAS Cloud (Etapa 2)** → Run workflow.
