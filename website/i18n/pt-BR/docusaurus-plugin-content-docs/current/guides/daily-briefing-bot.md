# Tutorial: Construa um Bot de Briefing Diário

Neste tutorial, você vai construir um bot de briefing pessoal que acorda toda manhã, pesquisa os tópicos que você se importa, resume as descobertas e entrega um briefing conciso direto no seu Telegram ou Discord.

Ao final, você terá um fluxo de trabalho totalmente automatizado combinando **busca na web**, **agendamento cron**, **delegação** e **entrega por mensagens** — sem precisar programar.

:::tip
Esta receita usa busca na web, resumo e TTS opcional — tudo incluído em uma assinatura do Portal. A configuração mais rápida é `work4you setup --portal`. Veja [Work4You Portal](/integrations/work4you-portal).
:::

## O Que Vamos Construir

Aqui está o fluxo:

1. **8h00** — O agendador cron dispara sua tarefa
2. **O Work4You inicia** uma nova sessão de agente com seu prompt
3. **A busca na web** traz as últimas notícias sobre seus tópicos
4. **O resumo** destila tudo em um formato de briefing limpo
5. **A entrega** envia o briefing para o seu Telegram ou Discord

Tudo isso roda sem intervenção manual. Você só precisa ler seu briefing com o café da manhã.

## Pré-requisitos

Antes de começar, certifique-se de ter:

- **Work4You instalado** — veja o [guia de instalação](/getting-started/installation)
- **Gateway em execução** — o daemon do gateway cuida da execução do cron:
  ```bash
  work4you gateway install   # Install as a user service
  sudo work4you gateway install --system   # Linux servers: boot-time system service
  # or
  work4you gateway           # Run in foreground
  ```
- **Chave de API do Firecrawl** — defina `FIRECRAWL_API_KEY` no seu ambiente para busca na web
- **Mensagens configuradas** (opcional, mas recomendado) — [Telegram](/user-guide/messaging/telegram) ou Discord configurado com um canal principal

:::tip Sem mensagens? Sem problema
Você ainda pode seguir este tutorial usando `deliver: "local"`. Os briefings serão salvos em `~/.work4you/cron/output/` e você pode lê-los quando quiser.
:::

## Passo 1: Teste o Fluxo Manualmente

Antes de automatizar qualquer coisa, vamos garantir que o briefing funciona. Inicie uma sessão de chat:

```bash
work4you
```

Depois digite este prompt:

```
Search for the latest news about AI agents and open source LLMs.
Summarize the top 3 stories in a concise briefing format with links.
```

O Work4You vai buscar na web, ler os resultados e produzir algo assim:

```
☀️ Your AI Briefing — March 8, 2026

1. Qwen 3 Released with 235B Parameters
   Alibaba's latest open-weight model matches GPT-4.5 on several
   benchmarks while remaining fully open source.
   → https://qwenlm.github.io/blog/qwen3/

2. LangChain Launches Agent Protocol Standard
   A new open standard for agent-to-agent communication gains
   adoption from 15 major frameworks in its first week.
   → https://blog.langchain.dev/agent-protocol/

3. EU AI Act Enforcement Begins for General-Purpose Models
   The first compliance deadlines hit, with open source models
   receiving exemptions under the 10M parameter threshold.
   → https://artificialintelligenceact.eu/updates/

---
3 stories • Sources searched: 8 • Generated by Work4You
```

Se isso funcionar, você está pronto para automatizar.

:::tip Itere no formato
Experimente prompts diferentes até obter uma saída que você goste. Adicione instruções como "use cabeçalhos com emoji" ou "mantenha cada resumo em até 2 frases". O que você definir vai para a tarefa cron.
:::

## Passo 2: Crie a Tarefa Cron

Agora vamos agendar isso para rodar automaticamente toda manhã. Você pode fazer isso de duas formas.

Antes de criar tarefas cron, garanta que o Work4You tenha um modelo e um provedor padrão configurados globalmente. Se quiser que uma tarefa específica use valores diferentes, defina substituições explícitas de modelo/provedor por tarefa ao criá-la.

### Opção A: Linguagem Natural (no chat)

Simplesmente diga ao Work4You o que você quer:

```
Every morning at 8am, search the web for the latest news about AI agents
and open source LLMs. Summarize the top 3 stories in a concise briefing
with links. Use a friendly, professional tone. Deliver to telegram.
```

O Work4You vai criar a tarefa cron para você usando a ferramenta unificada `cronjob`.

### Opção B: Comando de Barra da CLI

Use o comando `/cron` para mais controle:

```
/cron add "0 8 * * *" "Search the web for the latest news about AI agents and open source LLMs. Find at least 5 recent articles from the past 24 hours. Summarize the top 3 most important stories in a concise daily briefing format. For each story include: a clear headline, a 2-sentence summary, and the source URL. Use a friendly, professional tone. Format with emoji bullet points and end with a total story count."
```

### A Regra de Ouro: Prompts Autocontidos

:::warning Conceito crítico
As tarefas cron rodam em uma sessão **completamente nova** — sem memória das suas conversas anteriores, sem contexto sobre o que você "configurou antes". Seu prompt precisa conter **tudo** o que o agente precisa para fazer a tarefa.
:::

**Prompt ruim:**
```
Do my usual morning briefing.
```

**Prompt bom:**
```
Search the web for the latest news about AI agents and open source LLMs.
Find at least 5 recent articles from the past 24 hours. Summarize the
top 3 most important stories in a concise daily briefing format. For each
story include: a clear headline, a 2-sentence summary, and the source URL.
Use a friendly, professional tone. Format with emoji bullet points.
```

O prompt bom é específico sobre **o que pesquisar**, **quantos artigos**, **qual formato** e **qual tom**. É tudo o que o agente precisa de uma só vez.

## Passo 3: Personalize o Briefing

Uma vez que o briefing básico funcione, você pode ser criativo.

### Briefings Multi-Tópico

Cubra várias áreas em um único briefing:

```
/cron add "0 8 * * *" "Create a morning briefing covering three topics. For each topic, search the web for recent news from the past 24 hours and summarize the top 2 stories with links.

Topics:
1. AI and machine learning — focus on open source models and agent frameworks
2. Cryptocurrency — focus on Bitcoin, Ethereum, and regulatory news
3. Space exploration — focus on SpaceX, NASA, and commercial space

Format as a clean briefing with section headers and emoji. End with today's date and a motivational quote."
```

### Usando Delegação para Pesquisa Paralela

Para briefings mais rápidos, diga ao Work4You para delegar cada tópico a um sub-agente:

```
/cron add "0 8 * * *" "Create a morning briefing by delegating research to sub-agents. Delegate three parallel tasks:

1. Delegate: Search for the top 2 AI/ML news stories from the past 24 hours with links
2. Delegate: Search for the top 2 cryptocurrency news stories from the past 24 hours with links
3. Delegate: Search for the top 2 space exploration news stories from the past 24 hours with links

Collect all results and combine them into a single clean briefing with section headers, emoji formatting, and source links. Add today's date as a header."
```

Cada sub-agente pesquisa de forma independente e em paralelo, e depois o agente principal combina tudo em um único briefing polido. Veja a [documentação de Delegação](/user-guide/features/delegation) para mais detalhes sobre como isso funciona.

### Agendamento Somente em Dias Úteis

Não precisa de briefings nos fins de semana? Use uma expressão cron que aponte para segunda a sexta:

```
/cron add "0 8 * * 1-5" "Search for the latest AI and tech news..."
```

### Briefings Duas Vezes ao Dia

Tenha uma visão geral pela manhã e um recapitulativo à noite:

```
/cron add "0 8 * * *" "Morning briefing: search for AI news from the past 12 hours..."
/cron add "0 18 * * *" "Evening recap: search for AI news from the past 12 hours..."
```

### Adicionando Contexto Pessoal com Memória

Se você tem [memória](/user-guide/features/memory) ativada, pode armazenar preferências que persistem entre sessões. Mas lembre-se — as tarefas cron rodam em sessões novas, sem memória conversacional. Para adicionar contexto pessoal, incorpore-o diretamente no prompt:

```
/cron add "0 8 * * *" "You are creating a briefing for a senior ML engineer who cares about: PyTorch ecosystem, transformer architectures, open-weight models, and AI regulation in the EU. Skip stories about product launches or funding rounds unless they involve open source.

Search for the latest news on these topics. Summarize the top 3 stories with links. Be concise and technical — this reader doesn't need basic explanations."
```

:::tip Ajuste a persona
Incluir detalhes sobre para quem o briefing é *destinado* melhora drasticamente a relevância. Diga ao agente seu papel, interesses e o que pular.
:::

## Passo 4: Gerencie Suas Tarefas

### Liste Todas as Tarefas Agendadas

No chat:
```
/cron list
```

Ou pelo terminal:
```bash
work4you cron list
```

Você verá uma saída assim:

```
ID          | Name              | Schedule    | Next Run           | Deliver
------------|-------------------|-------------|--------------------|--------
a1b2c3d4    | Morning Briefing  | 0 8 * * *   | 2026-03-09 08:00   | telegram
e5f6g7h8    | Evening Recap     | 0 18 * * *  | 2026-03-08 18:00   | telegram
```

### Remova uma Tarefa

No chat:
```
/cron remove a1b2c3d4
```

Ou peça de forma conversacional:
```
Remove my morning briefing cron job.
```

O Work4You vai usar `cronjob(action="list")` para encontrá-la e `cronjob(action="remove")` para excluí-la.

### Verifique o Status do Gateway

Certifique-se de que o agendador está realmente rodando:

```bash
work4you cron status
```

Se o gateway não estiver rodando, suas tarefas não vão executar. Instale-o como um serviço em segundo plano para maior confiabilidade:

```bash
work4you gateway install
# or on Linux servers
sudo work4you gateway install --system
```
